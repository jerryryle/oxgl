- [ ] 1.1 Export `server.mjs`'s request path resolution, pass the suite root from `run.mjs` through `pool.mjs` to the page child in its options JSON, and set `CLOSURE_IMPORT_SCRIPT` in `installShim` as design.md describes (after-parsing check, same-origin check, file read through the shared resolution or the given source text, inline `<script>` with a `sourceURL` comment appended to `document.head`, `true` on success and `false` otherwise). Verify with `npm run lint`.
- [ ] 1.2 Add fixture pages under `test/fixtures/conformance/` with a minimal `base.js`-style loader that imports through `goog.importScript_`'s contract: `CLOSURE_IMPORT_SCRIPT` if set, otherwise `document.write('<script src=…>')` as `goog.writeScriptTag_` does. Use one external script before the `goog.require` script, as deqp pages have, so the jsdom ordering bug reproduces without the hook. Cover the spec's four scenarios: a namespace used by a later `<body>` script (`PASS`), an imported file that throws while the page then completes with passing results (`PASS` with the error recorded and naming the imported file), a missing imported file (`FAIL`, no harness error), and a require from a `load` listener, so it runs after `DOMContentLoaded` and not while jsdom is still draining its script queue (`FAIL`, the error recorded). Add them to `test/conformance-harness.test.mjs`, confirm the first fixture fails with the hook removed, and run `npm test` with `OXGL_BACKEND=software`.
- [ ] 1.3 Check the hook against real `base.js` (absolute `src` URLs, the `deps.js` import at load, `written` bookkeeping) outside `npm test`, which stays offline. After `webgl-idl-constants` is merged and this branch is updated from `main`, run `npm run conformance -- --suite webgl2 --filter deqp/functional/gles3/attriblocation.html` on Linux arm64 with `OXGL_BACKEND=software`. Verify in the report that the page got past loading: it recorded at least one result, or its recorded error or first failure comes from a `deqp/` file (its stack names a `deqp/` URL), and in neither case is it `functional is not defined`.
